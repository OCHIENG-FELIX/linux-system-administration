# Linux System Administration Fundamentals

## Project Overview

This project documents fundamental Linux system administration concepts and common administrative tasks relevant to IT support and infrastructure environments.

It focuses on Linux command-line operations, file management, user administration, permissions, process management, system monitoring, and troubleshooting common system issues.

The project is designed to demonstrate foundational Linux administration knowledge through structured technical documentation and simulated troubleshooting scenarios.

## Project Objectives

- Understand Linux operating system fundamentals.
- Navigate the Linux filesystem.
- Perform basic file and directory management.
- Understand Linux users and groups.
- Manage file and directory permissions.
- Monitor and manage running processes.
- Inspect system resource utilization.
- Understand Linux service management.
- Investigate common system administration problems.
- Apply structured troubleshooting procedures.

## Environment

- Operating System: Linux
- Example Distributions: Ubuntu and Kali Linux
- Interface: Linux Command Line
- Tools: Terminal, Bash, systemctl, journalctl, top, df, free
- Documentation Platform: GitHub
