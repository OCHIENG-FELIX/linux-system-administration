# Linux Fundamentals

## Overview
Linux is an open-source operating system widely used in servers, cloud infrastructure, networking, cybersecurity, and enterprise IT environments.

Linux provides command-line tools that allow administrators to manage files, users, permissions, processes, services, and system resources.

## Common Linux Distributions
- Ubuntu
- Debian
- Fedora
- Red Hat Enterprise Linux
- Kali Linux

## Linux Terminal
The terminal provides a command-line interface for interacting with the operating system.

## Essential Commands

### Display Current Directory
```bash
pwd
```

### List Files and Directories
```bash
ls
ls -l
ls -la
```

### Change Directory
```bash
cd /home
```

### Display Current User
```bash
whoami
```

### Display System Information
```bash
uname -a
```

### Display Command Help
```bash
man ls
```

## Linux File System
Linux organizes files and directories under a single root directory represented by `/`.

Important directories include:

| Directory | Purpose |
|---|---|
| `/` | Root directory |
| `/home` | User home directories |
| `/etc` | System configuration |
| `/var` | Variable data and logs |
| `/tmp` | Temporary files |
| `/bin` | Essential user commands |
| `/root` | Root user's home directory |
| `/dev` | Device files |

## Importance in IT Support
Linux knowledge helps technicians manage systems, investigate technical problems, understand server environments, and perform routine administration tasks.
