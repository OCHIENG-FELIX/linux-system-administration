# Linux System Monitoring

## Overview
System monitoring helps administrators evaluate system performance, storage availability, memory usage, and operational health.

## Essential Monitoring Commands

### System Uptime
```bash
uptime
```

### Memory Usage
```bash
free -h
```

### Disk Space
```bash
df -h
```

### Directory Storage Usage
```bash
du -sh /home
```

### System Information
```bash
uname -a
```

### Running Processes
```bash
top
```

### System Logs
```bash
journalctl
```

### Recent System Messages
```bash
dmesg
```

## Important Monitoring Areas
- CPU utilization.
- Memory usage.
- Disk space.
- Running processes.
- System logs.
- Service availability.
- System uptime.

## Relevance to IT Support
System monitoring allows technicians to identify performance problems, investigate system failures, and detect potential resource shortages before they become serious.
