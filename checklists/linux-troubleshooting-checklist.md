# Linux Troubleshooting Checklist

## 1. Identify the Problem
- [ ] Record the reported issue.
- [ ] Identify the affected user.
- [ ] Establish when the issue started.
- [ ] Record error messages.
- [ ] Determine the impact.

## 2. Initial Investigation
- [ ] Check system status.
- [ ] Review recent changes.
- [ ] Identify affected applications or services.
- [ ] Check user permissions.

## 3. Diagnostic Checks
- [ ] Inspect processes using `top`.
- [ ] Check memory using `free -h`.
- [ ] Check disk space using `df -h`.
- [ ] Inspect permissions using `ls -l`.
- [ ] Review system logs using `journalctl`.
- [ ] Check service status using `systemctl`.

## 4. Resolution
- [ ] Identify the likely cause.
- [ ] Select an appropriate corrective action.
- [ ] Obtain authorization where necessary.
- [ ] Protect important files and system data.
- [ ] Escalate complex or high-risk issues.

## 5. Verification
- [ ] Confirm the issue has been resolved.
- [ ] Test affected applications or services.
- [ ] Check system stability.
- [ ] Confirm with the user.

## 6. Documentation
- [ ] Record diagnostic findings.
- [ ] Document corrective actions.
- [ ] Record the final outcome.
- [ ] Provide preventive recommendations.
