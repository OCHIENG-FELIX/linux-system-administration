# Linux System Maintenance Checklist

## System Health
- [ ] Check system uptime.
- [ ] Monitor CPU utilization.
- [ ] Review memory utilization.
- [ ] Check disk space.
- [ ] Inspect system logs.

## User Management
- [ ] Review authorized user accounts.
- [ ] Review group memberships.
- [ ] Check administrative privileges.
- [ ] Apply account security policies.

## File Management
- [ ] Review important directories.
- [ ] Check file ownership.
- [ ] Verify file permissions.
- [ ] Protect sensitive configuration files.
- [ ] Confirm backups are available.

## Process and Service Management
- [ ] Review running processes.
- [ ] Check critical service status.
- [ ] Investigate failed services.
- [ ] Review resource consumption.

## Security
- [ ] Apply approved security updates.
- [ ] Review access permissions.
- [ ] Protect credentials.
- [ ] Follow organizational security policies.

## Documentation
- [ ] Record maintenance activities.
- [ ] Document identified issues.
- [ ] Record corrective actions.
- [ ] Escalate unresolved problems.
